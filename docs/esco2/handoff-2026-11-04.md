  named in the master plan). Do not write held-out details to any shared notes folder.
  Only an independent evaluator runs it, and it reports aggregates only.
- No deploy, migration or secret change without Santiago's explicit approval.
- Do not touch `chat.tsx`, `src/supabase/functions/server/` or the Telegram bot.
- Never print the OpenRouter key. `scripts/esco2/clave.ts` reads it from `ESCO2_ENV`,
  `docs/Esco 2.0/.env` or the root `.env.local`.
- "Today" is Bogotá local time. In `src/` use `src/utils/esco2/fechaCalendario.ts`; the guard
  `hatoFechaLocalGuard.test.ts` forbids `toISOString().slice(0,10)`.
- Production reads go through the read-only route only (Composio
  `SUPABASE_RUN_READ_ONLY_QUERY`, account `escocia-os`). Hypothesis tests that need writes use
  `select public.po_sonda(...)`, which always rolls back.
