Date: 2026-11-04. Owner: QA. Status: prepared for freeze before P1 comparison.
Scope: isolated offline P0/P1. No held-out material, paid calls, production reads or runtime integration.

The source tables and independent literal expectations are in
`scripts/esco2/recovery/qa/scenarios.ts`. Expected values came from manual table arithmetic,

Each fixture includes a Given/When/Then behavioral criterion. The denominator is exactly
16 fresh scenarios, four per family. A scenario passes only if every obligation passes.
All non-predeclared refusals, errors, missing parts and unnecessary clarifications fail.

## Oracle and answer checks

Compare every required semantic claim on obligation, entity type/ID/label, metric, unit,
cohort, date basis, interval, value state and exact scalar/set. Required qualifier strings
are part of the frozen oracle. Claim/provenance ordering is incidental; ranking membership
order is meaningful. The emitted fact set must match the expected set. Unrequested extra claims fail the declared answer contract as ungraded coverage; the oracle does not call a potentially true extra claim a critical false assertion. No unsolicited factual
claim can be accepted just because its number occurs elsewhere. Provenance must be nonempty
and use source IDs or the declared visible source scope; question numbers cannot supply it.

The answer must be a deterministic rendering of its validated claims and dispositions.
A result with correct hidden claims and modified factual text fails. All mandatory qualifiers
must appear in the factual rendering. No free-form model factual composition is authorized
for either repaired option. A validated legitimate result must pass the candidate validator.
A validator rejecting everything fails the positive controls.

## Predefined adversarial mutations

Eight mutation classes are frozen: wrong entity ID; wrong unit; wrong date basis; wrong exact
set member; removed required qualifier; unsupported question-only number777; skipped obligation;
and unread association converted into verified-empty. Each class has a canonical legitimate
control and one deterministic mutation. The candidate's validation boundary must reject every
mutation. The independent QA oracle must also reject them, reported separately. Extra rendered
text mutation is an answer-boundary control and is not folded into the eight-class count.

Critical failure means any wrong factual semantic tuple, removed mandatory scope qualifier, unrelated contributor provenance or security breach. Incomplete safe
answers fail coverage; they do not automatically count as fabricated facts. Report scenario
pass and critical flags separately. Baseline failures are experimental results, not a failing
harness setup. Neither repaired option passes unless all16 obligations, eight mutation classes,
positive controls and permission/isolation checks pass.

## Reproducibility and stages

Freeze SHA256 of contract, fixtures, this rubric and oracle before comparisons. A later reference
correction requires explicit authority, documented reason, version/hash and uniform reruns.
Do not tune expected outputs to a candidate. Candidate implementation fixes may rerun the same
frozen inputs, with final source hashes and a statement that this is development-set evidence.

Run stage A approved intents; stage B candidate validator mutations and answer integrity; then
stage C scripted planning with real orchestration and a synthetic PGlite RLS boundary. Block
network fetch in the runner; inject every LLM response and account for calls. No existing paid
`e2e-local.ts` import. Exercise active Gerencia success, denied roles, inactive/profileless and
invalid JWT, owner reset, closed fixed reads and legacy isolation. The production HTTP handler
has no responder injection seam: distinguish unchanged-handler checks from any local candidate
wrapper using real authorization/source functions. Never describe a local wrapper as deployed
HTTP integration.

Report payload bytes, deterministic latency, implementation files/lines and special branches
on identical inputs. These are local measurements, not a provider SLA. This experiment cannot
certify generalization, five-domain acceptance, actual production completeness or deployment.
Stop before P2 regardless of the result.
