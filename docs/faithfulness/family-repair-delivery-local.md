## Mechanisms and correction

- One closed application metric contract now connects the offered schema,
  dispatcher, source reader and factual composer. Scalar, array and omitted metrics
  are tested through the actual shared loop. Presentation metadata is not a source
  filter. Malformed arguments, source failure, unknown coverage and budget failure
  retain distinct closed codes/stages without exception bodies.
- Registered product quantities and historical labor costs are independently
  derived from their own fresh, projected records, preserving identity, unit and
  date window. Labor does not require a lot, current wage or consumption source.
  Shared task attribution and unknown activity membership remain partial/unknown.
- Actual-start cohort, planned-start cohort and recorded activity window remain
  separate. A planned-start cohort is not silently converted into an actual
  consumption/work window; the supported date part can still answer independently.
- Literal date comparison uses recorded fields. Theory is a closed dose-times-
  planned-canecas operation with verified inputs, compatible atomic units and a
  visible formula. Only explicit positive current-user calculation intent grants
  this part; a model metric, historical intent or an application name cannot.
- Orphan/ambiguous references clarify before source/model access. A unique prior
  user selector and valid timestamp can propose scope for fresh catalog binding;
  assistant prose/IDs never bind it. A separable independent subquestion remains
  answerable. Current explicit selectors take precedence.
- Normal/fallback factual composition stays common. An argument repair can use
  the next existing round (maximum remains three) with minimized typed protocol;
  raw source, model factual prose and contaminated history are not reintroduced.
